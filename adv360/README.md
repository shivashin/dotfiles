# Kinesis Advantage360（SmartSet）の設定

Kinesis Advantage360 の設定ファイルのバックアップ。Pro ではないモデル（左右をケーブルでつなぎ、SmartSet で設定するもの）用。

キー割り当てはキーボードの中に保存されていて、Mac には何も入れていない。そのため、どの Mac につないでも同じ配列で使える。このディレクトリのファイルは、キーボードの v-Drive（USB ドライブとして見える領域）からコピーしたもの。フォルダの構成も v-Drive と同じにしてある。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `layouts/layout1.txt` 〜 `layout9.txt` | プロファイル 1〜9 のリマップとマクロ。標準から変えたキーだけが書かれる。今使っているのは `layout1.txt` だけで、ほかは空 |
| `lighting/led1.txt` 〜 `led9.txt` | プロファイル 1〜9 の LED の色と、何を表示するか |
| `settings/settings.txt` | 今のプロファイル、配列（`country=us`）、ファームウェアのバージョン（左右とも 1.0.5）など。キーボードが書き込むファイルで、Kinesis は手で編集しないように書いている |

## キー配列の図の見方

図は、左右のキーボードを上から見た形で描いている。親指のキーは、左手ではメインのキーの右下、右手では左下にある。

- 縦に 2 段ある親指のキー（左手の `BS`・`Del`、右手の `Enter`・`Space` の位置）は、1 つの大きなキー。名前は 2 段の境目に書いている。
- `kp`: キーパッドレイヤーに切り替えるキー（5 の右）
- `SS`: SmartSet キー（歯車の刻印、6 の左）。設定用で、割り当ては変えられない
- `fn`: fn レイヤーに切り替えるキー（左右の小指）
- `Hk1`〜`Hk4`: ホットキー（キーキャップに丸数字の 1〜4）。標準では何も出ない
- `Cmd`: macOS の ⌘。Windows キー（`lwin`）で、Mac では ⌘ になる
- `Alt`: macOS の ⌥
- `BS`: Backspace
- `*`: プロファイル 1 で標準から変えたキー

## ベースレイヤー（今使っている配列、プロファイル 1）

左手:

```
+------+------+------+------+------+------+------+
| Esc* |  1   |  2   |  3   |  4   |  5   |  kp  |
+------+------+------+------+------+------+------+
| Tab  |  Q   |  W   |  E   |  R   |  T   |  [*  |
+------+------+------+------+------+------+------+------+------+
| Ctrl*|  A   |  S   |  D   |  F   |  G   |  '*  | Ctrl | Alt  |
+------+------+------+------+------+------+------+------+------+
|Shift |  Z   |  X   |  C   |  V   |  B   |      |      | Home |
+------+------+------+------+------+------+Space*|Shift*+------+
|  fn  |  `   | Cmd* | Left |Right |      |      |      | Cmd* |
+------+------+------+------+------+      +------+------+------+
```

右手:

```
              +------+------+------+------+------+------+------+
              |  SS  |  6   |  7   |  8   |  9   |  0   |  -   |
              +------+------+------+------+------+------+------+
              |  ]*  |  Y   |  U   |  I   |  O   |  P   |  \   |
+------+------+------+------+------+------+------+------+------+
| Cmd  | Ctrl |  -*  |  H   |  J   |  K   |  L   |  ;   |  =*  |
+------+------+------+------+------+------+------+------+------+
| End* |      |      |  N   |  M   |  ,   |  .   |  /   |Shift |
+------+ BS*  |Enter*+------+------+------+------+------+------+
|Shift*|      |      |      |  Up  | Down |  [   |  ]   |  fn  |
+------+------+------+      +------+------+------+------+------+
```

変えたキーと、`layouts/layout1.txt` の行の対応:

- 数字の列の左端の `=` を Esc にした（`[eql]>[esc]`）。代わりに、右手の `'` の位置を `=` にした（`[apos]>[eql]`）
- A の左の Esc を Ctrl にした（`[esc]>[lctr]`）
- 左手の下の列の Caps Lock を ⌘ にした（`[caps]>[lwin]`）
- ホットキーを `[` `'` `]` `-` にした（`[hk1]>[obrk]`、`[hk2]>[apos]`、`[hk3]>[cbrk]`、`[hk4]>[hyph]`）
- 左手の親指の Backspace、Delete、End を Space、Shift、⌘ にした（`[bspc]>[spc]`、`[del]>[lshf]`、`[end]>[lwin]`）。Home はそのまま
- 右手の親指の Page Up、Page Down、Enter、Space を End、Shift、Backspace、Enter にした（`[pgup]>[end]`、`[pgdn]>[lshf]`、`[ent]>[bspc]`、`[spc]>[ent]`）

## レイヤー

レイヤーは 5 つある。`layout*.txt` では、`<base>` などの見出しの下に書いた行が、そのレイヤーの設定になる。

| レイヤー | 見出し | 入り方 | プロファイル 1 での変更 | レイヤーの LED |
|---|---|---|---|---|
| ベース | `<base>` | ふだんの状態 | 上の図の `*` のキー | 消灯 |
| キーパッド | `<keypad>` | `kp` を押すたびに切り替わる | なし | 白 |
| fn（fn1） | `<function1>` | `fn` を押しているあいだだけ | なし | 青 |
| fn2 | `<function2>` | 標準では入るキーがない。`[fn2s]`（押しているあいだ）か `[fn2t]`（切り替え）をどこかのキーに割り当てると使える | なし | 消灯 |
| fn3 | `<function3>` | fn2 と同じ。`[fn3s]` か `[fn3t]` を割り当てる | なし | 消灯 |

リマップは、書いたレイヤーにしか効かない（User's Manual の 6.1）。プロファイル 1 のリマップは `<base>` にしか書いていないので、キーパッドレイヤーと fn レイヤーでは、ほとんどのキーが標準の配列（プロファイル 0）の動作になるはず。例えば、左手の親指の大きいキーは Space と Shift ではなく Backspace と Delete、A の左は Ctrl ではなく Esc になる。`fn` を押しながら左手の親指の大きいキーを押すと確かめられる。

### キーパッドレイヤー

左手は標準の配列と同じ。右手が次のようになる（`KP` が付いたものはテンキーのキー）。

```
              +------+------+------+------+------+------+------+
              |  SS  |  6   | Num  | KP=  | KP/  | KP*  |  -   |
              +------+------+------+------+------+------+------+
              | Hk3  |  Y   | KP7  | KP8  | KP9  | KP-  |  \   |
+------+------+------+------+------+------+------+------+------+
| Cmd  | Ctrl | Hk4  |  H   | KP4  | KP5  | KP6  | KP+  |  '   |
+------+------+------+------+------+------+------+------+------+
| PgUp |      |      |  N   | KP1  | KP2  | KP3  |KPEnt |Shift |
+------+Enter | KP0  +------+------+------+------+------+------+
| PgDn |      |      |      |  Up  | Down | KP.  |  ]   |  fn  |
+------+------+------+      +------+------+------+------+------+
```

この図は、Advantage360 Pro の標準のキーマップのキーパッドレイヤーをもとに描いた。SmartSet のマニュアルにある「右手の 18 キーがテンキーになる」とも数が合う。違うところがあれば、キーキャップの前面の右下の刻印に合わせて直す。

### fn レイヤー

数字の列だけが F1〜F12 になる。ほかのキーは標準の配列と同じ。

左手の数字の列:

```
+------+------+------+------+------+------+------+
|  F1  |  F2  |  F3  |  F4  |  F5  |  F6  |  kp  |
+------+------+------+------+------+------+------+
```

右手の数字の列:

```
+------+------+------+------+------+------+------+
|  SS  |  F7  |  F8  |  F9  | F10  | F11  | F12  |
+------+------+------+------+------+------+------+
```

- fn レイヤーから戻れなくなったときは、左右の `fn` を同時に押すとベースレイヤーに戻る。
- fn2 と fn3 は、どのプロファイルでも使っていない。

## LED（プロファイル 1）

LED は、左右それぞれの親指のキーの上に 3 つずつある。

```
左手:  [ IND1 ]   [ IND2 ]   [ IND3 ]        右手:  [ IND4 ]   [ IND5 ]   [ IND6 ]
        Caps       Profile    Layer                  Num        Scroll     Layer
```

| LED | 表示するもの | 色 |
|---|---|---|
| `IND1` | Caps Lock | 白 |
| `IND2` | 今のプロファイル | 消灯（`[0][0][0]`） |
| `IND3` / `IND6` | 今のレイヤー | 上のレイヤーの表のとおり |
| `IND4` | Num Lock | 白 |
| `IND5` | Scroll Lock | 白 |

プロファイル 2〜9 は、`IND2` の色がプロファイルごとに違うだけで、fn2 は緑、fn3 は赤で光る。

## プロファイルの切り替え

`SmartSet` を押しながら数字の列の `1`〜`9` を押す。プロファイル 0 は工場出荷時の配列で、リマップできない。今はプロファイル 1 を使っている（`settings/settings.txt` の `profile=1`）。

## v-Drive を開く・閉じる

キーボードの設定ファイルは、v-Drive を開いているあいだだけ Mac から見える。ファイルのコピーにも SmartSet App にも v-Drive が必要。

| 操作 | キー | LED |
|---|---|---|
| 開く | `SmartSet` を押しながら Hotkey 3（Y の左） | 4 回点滅したあと、開いているあいだは青く点滅する |
| 閉じる | 開くときと同じ | 点滅して、青い点滅が止まる |
| 開いたまま変更を反映する（Refresh） | `SmartSet` を押しながら Hotkey 4（H の左） | |

- 開くと、Mac に USB ドライブとして見える。この Mac では「NO NAME」という名前になる（マニュアルでは「Adv360」）。
- 閉じる前に、編集したファイルを保存して閉じ、Finder でドライブを取り出す。macOS では取り出しのエラーがよく出るが、Kinesis によると無視してよい。
- v-Drive のファイルを変えても、v-Drive を閉じるか Refresh するまで、キーボードには反映されない。
- 開いているあいだは、リマップなどキーボードだけで行う設定は使えない。

## キーボードからコピーする（バックアップ）

1. v-Drive を開く。
2. ファイルをコピーする。macOS が v-Drive に作る `._layout1.txt` のようなファイルはコピーしない。

   ```sh
   V="/Volumes/NO NAME"
   cp "$V"/layouts/layout[1-9].txt ~/dotfiles/adv360/layouts/
   cp "$V"/lighting/led[1-9].txt ~/dotfiles/adv360/lighting/
   cp "$V"/settings/settings.txt ~/dotfiles/adv360/settings/
   ```

3. `git diff` で変わったところを確認してからコミットする。
4. v-Drive を閉じる。

## キーボードに書き戻す

1. v-Drive を開く。
2. 戻したいファイルだけを、v-Drive の同じフォルダにコピーする。

   ```sh
   cp ~/dotfiles/adv360/layouts/layout1.txt "/Volumes/NO NAME/layouts/"
   ```

3. v-Drive を閉じる。閉じたときに、書き戻したファイルの内容がキーボードに反映される。

- `settings/settings.txt` は書き戻さない。キーボードが書き込むファイルで、Kinesis は手で編集しないように書いている。
- ファイルを書いている途中で v-Drive を閉じたりケーブルを抜いたりすると、ファイルが壊れることがある。
- 書き方を間違えると、そのキーは標準の動作のままになる。
- 全プロファイルを消して工場出荷時に戻すには、`SmartSet` と Hotkey 4 を押しながらケーブルをつなぐ。今のプロファイルだけ消すには `SmartSet` + 右 Ctrl + Enter。どちらも、このディレクトリのファイルを書き戻せば元に戻る。

## SmartSet App（GUI）で変える

SmartSet App は、Kinesis が配っている Advantage360 用の設定アプリ。キーの割り当て、マクロ、タップと長押しを GUI で設定できる。アプリは v-Drive の `layout*.txt` と `led*.txt` を書き換えるので、GUI で変えた内容も、このディレクトリのファイルと同じ形で保存される。

- ダウンロード: [Advantage 360 SmartSet App（macOS v1.0.5）](https://kinesis-ergo.com/download/advantage-360-smartset-app-macos-v1-0-5/)
- Windows 版やほかのバージョン: [Advantage360 のサポートページの SmartSet App の欄](https://kinesis-ergo.com/support/kb360/#smartset-app)

インストーラはない。ダウンロードした zip を展開して、中のアプリをそのまま起動する。

手順:

1. v-Drive を開く。
2. SmartSet App を起動する。画面の指示に従って、v-Drive につなぐ。
3. キーの割り当てを変えて保存する。
4. v-Drive を閉じる（または Refresh する）と、キーボードに反映される。
5. 「キーボードからコピーする」の手順で dotfiles を更新し、`git diff` で変わったキーを確認してからコミットする。

- v1.0.5 では、キーの検索、レイヤーごとのリセット、タップと長押しの画面がある。
- マクロをタップと長押しで使うには、ファームウェアが 1.0.69 以降である必要がある。このキーボードは 1.0.5 なので使えない。

## `layout*.txt` の書き方

| 書き方 | 例 | 意味 |
|---|---|---|
| `[位置]>[動作]` | `[hk1]>[obrk]` | Hotkey 1 を `[` にする |
| `{位置}>{動作}{動作}...` | `{tab}>{-lshf}{h}{+lshf}{i}` | マクロ。`-` は押す、`+` は離す |
| `[位置]>[タップ][t&h<ミリ秒>][長押し]` | `[caps]>[caps][t&h250][esc]` | 短く押したときと長く押したときで動作を変える。Kinesis は 250 ミリ秒を勧めている |
| 行の先頭に `*` | `*[hk1]>[obrk]` | その行を無効にする |

- 位置の名前は、標準の配列でそのキーが出す文字の名前（`eql`、`apos`、`hk1` など）。大文字と小文字は区別しない。
- Shift を押した文字（`!` など）は、リマップではなくマクロで書く。
- ファームウェアが古い（1.0.5）ので、新しい書き方は使えないことがある。最新のマニュアルはファームウェア 1.0.79 までを対象にしている。
